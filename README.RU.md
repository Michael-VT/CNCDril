# CNCDril - Оптимизатор сверловки для ЧПУ

Мультиплатформенный оптимизатор сверловочных файлов для преобразования P-CAD/Altium .drl файлов в оптимизированный G-Code для ЧПУ станков.

## Особенности

- **Несколько платформ**: Delphi VCL, Python CLI/GUI, Node.js CLI, веб-версия и автономная HTML-версия
- **Алгоритмы оптимизации**:
  - SortByX: Сортировка отверстий по координате X
  - SortByY: Сортировка отверстий по координате Y
  - SortByPath (OPTICS): Оптимизация на основе расстояния
- **Визуализация**: Интерактивный предпросмотр пути сверления с анимацией
- **Мультиязычность**: Поддержка 6 языков (EN, RU, UK, PT, DE, FR)
- **Кроссплатформенность**: Windows, Linux, macOS и веб-браузеры

## Версии

### Версия Delphi (оригинал)
- **Расположение**: `delphi/`
- **Требования**: Delphi 6.0 или выше
- **Особенности**: Полнофункциональное десктопное приложение VCL
- **Использование**: Открыть `CNCDril.dpr` в IDE Delphi и скомпилировать

### Версия Python
- **Расположение**: `python/`
- **Требования**: Python 3.7+, matplotlib, numpy
- **Особенности**: CLI и GUI интерфейсы
- **Тесты**: `python/test_cncdril.py` (13 тестов)
- **Установка**: См. `python/README.md`

### Версия Node.js
- **Расположение**: `nodejs/`
- **Требования**: Node.js 14+ (нулевые зависимости)
- **Особенности**: CLI с поддержкой 6 языков, те же алгоритмы, что и во всех остальных версиях
- **Тесты**: `nodejs/test/test.mjs` (13 тестов)
- **Использование**: `node cncdril.mjs input.drl -o output.nc`

### Веб-версия
- **Расположение**: `web/`
- **Требования**: Современный веб-браузер (сервер не требуется)
- **Особенности**: Drag-and-drop, интерактивная визуализация, мультиязычность
- **Тесты**: `web/test/test.mjs` (10 тестов)
- **Использование**: Открыть `web/index.html` в браузере

### Автономная HTML-версия
- **Расположение**: `standalone/cncdril.html`
- **Требования**: Только современный веб-браузер — без сервера, без установки
- **Особенности**: Единый автономный HTML-файл со встроенными CSS и JavaScript
- **Использование**: Открыть `standalone/cncdril.html` в любом браузере (работает по протоколу file://)
- **Та же функциональность**, что и в веб-версии: парсинг DRL, 3 алгоритма оптимизации, генерация G-Code, интерактивная визуализация на canvas, 6 языков

## Быстрый старт

### Версия Delphi
1. Открыть `delphi/CNCDril.dpr` в IDE Delphi
2. Скомпилировать и запустить
3. Загрузить .drl файл и сгенерировать G-Code

### Версия Python
```bash
cd python
pip install -r requirements.txt
python cncdrill.py ../examples/RPCB0827_FIXTURE.DRL -o output.nc
```

### Версия Node.js
```bash
cd nodejs
node cncdril.mjs ../examples/RPCB0827_FIXTURE.DRL -o output.nc

# С выбором языка
node cncdril.mjs ../examples/RPCB0827_FIXTURE.DRL --language ru -o output.nc
```

### Веб-версия
```bash
cd web
python -m http.server 8000
# Перейти на http://localhost:8000
```

### Автономная HTML-версия
Открыть `standalone/cncdril.html` в любом современном веб-браузере. Сервер не требуется.

## Формат файлов

### Вход (.drl)
Сверловочные файлы P-CAD/Altium:
- Определения инструментов (T01C1.73)
- Координатные данные (X+005004Y+017894)
- Метрические и дюймовые единицы
- Несколько инструментов в файле

### Выход (.nc)
Стандартный G-Code для ЧПУ:
- Команды смены инструмента (T1 M6)
- Движения по безопасной высоте (G0 Z5.0)
- Операции сверления (G1 Z-2.0)
- Совместимость с большинством ЧПУ контроллеров

## Пример

Директория `examples/` содержит `RPCB0827_FIXTURE.DRL`:
- 7 инструментов (Ø1.73mm до Ø10.16mm)
- 102 отверстия всего
- Метрические единицы

## Оптимизация

Алгоритм OPTICS (Ordering Points To Identify the Clustering Structure) минимизирует расстояние перемещения инструмента:
1. Находит ближайшее не посещенное отверстие
2. Перемещается к этому отверстию
3. Повторяет пока все отверстия не будут посещены

Это обычно уменьшает общее расстояние перемещения на 30-50% по сравнению с несортированными путями.
